# Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Discover all cameras from a configurable go2rtc server.
- Open cameras in the go2rtc browser player by default.
- Support IINA, VLC, mpv, and other preferred applications through MP4, HLS, or RTSP.
- Keep a managed Root Search Script Command in sync for every camera.
- Automatically add new camera commands and remove commands for streams deleted from go2rtc.
- Support go2rtc base paths and optional HTTP Basic Auth.
